# 実機の受け入れ確認

## テンキーWidgetの利用できないボタン

- 金額を全消去し、グレーの「今日の支出を登録」を中央・左右から押す。アプリが開かず、登録もされないことを確認する。
- ジャンル選択の先頭でグレーの「前へ」、末尾でグレーの「次へ」を押す。ページ・入力内容を維持し、アプリを開かないことを確認する。
- 有効な数字キー・ページ送り・登録・取消は引き続きWidget内で動くことを確認する。


## Widgetから全画面入力を開く

1. Widget「全画面で支出を入力」をタップし、メニューを経由せず大きなテンキーの入力画面が開くことを確認する。小・中・大の配置に対応する。
2. 金額・ジャンル・支払元を指定して保存し、取消と再登録を確認する。「閉じる」で通常画面に戻り、履歴に重複なく反映されることを確認する。
3. 入力途中で閉じてWidgetから再度開き、入力内容を保持することを確認する。登録済みから開いた場合は空の次の入力へ進む。
4. 従来の操作はWidget一覧の「Widget内で支出を登録」で確認する。旧版へ戻す場合は `.rollback/20261027-before-fullscreen/restore-device.sh` を実行する。アプリを削除しない。


## 支出登録Widget

1. 更新後にアプリを一度開き、既存の取引・予算・契約・所有物を確認する。共有領域の準備失敗時はエラーが表示され、元の保存領域が保持される。
2. ホーム画面を長押しし、「編集」→「ウィジェットを追加」→「家計簿」→大サイズの「Widget内で支出を登録」を追加する。
3. アプリを終了し、Widgetで金額を入力する。「00」・削除・全消去を確認し、ジャンルと支払元をページ送りで選択する。選択画面の往復で金額を保持する。
4. 登録後もホーム画面に留まり、完了表示が出ることを確認する。同じ登録ボタンの連打で取引を増やさない。「取り消す」で支出と残高反映が戻り、金額を保持した入力画面へ戻ることを確認する。
5. 再登録してからアプリの履歴・口座残高を確認する。現金／銀行は残高減、カードは利用額増、未指定は口座記録なし。登録日は保存時点の当日、メモ空欄、節約可能オフ。
6. アプリでその取引を編集した後、Widgetの取消が拒否されることを確認する。「続けて入力」は金額のみリセットする。
7. アプリとWidgetの同時操作、複数Widgetでの入力共有、日付境界、拡大文字、VoiceOver、端末ロック中の操作を確認する。支出ジャンルや口座をアーカイブした場合、勝手に別の選択肢へ変更せず選び直せることを確認する。

JSONバックアップ形式はv4のまま。DB v5のWidget操作状態は家計簿バックアップには含めない。CloudKitを構成したビルドの移行・同期は別途2台で確認する。

## サブスクの一括確定・自動確定・履歴タグ

1. 今月分の未確定予定があるサブスクを複数用意し、「契約・固定費」の件数・合計額を確認する。「今月分をまとめて確定」をキャンセルし、未確定のままであることを確認する。
2. 再度実行して確定する。契約のカテゴリ・支払元・予定額で各支払日の取引ができ、同じ予定を再確定できないことを確認する。変動額は事前に予定を編集する。
3. 履歴で「管理・サブスク：契約名」のタグを確認する。手動取引には付かず、既存の保険などの支払や所有物に関連付けた取引はそれぞれのタグで識別できることを確認する。
4. 定額サブスクの「支払日に自動確定」を有効にして保存する。アプリ起動・復帰時に当月の期日到来分だけが記帳され、再起動しても重複しないことを確認する。過去月・将来日・変動額・設定オフ・終了済みは対象外。
5. 設定の再読込・バックアップ往復を確認する。支払元がアーカイブ済みなどで記帳できない場合はエラーになり、未確定のまま残ることを確認する。

自動確定はアプリの起動・復帰・再読込時に行う。アプリ終了中の定刻実行や実際の送金を行う機能ではない。

## サブスクリプションのサービス名選択

1. 管理 → 契約・サブスクリプション・保険 → 契約を追加で、「サービスから選ぶ」が表示されることを確認する。初回案内の「サブスクリプションを追加」からも確認する。
2. 候補一覧の5カテゴリ・14サービスと「その他・手入力」を確認する。iPhone 12 mini相当の画面と大きな文字サイズで、下端の候補まで選べることを確認する。
3. 金額・支払周期・カテゴリ・開始日・最初の支払日・支払元を指定してからサービスを選び、名前以外の値が一致することを確認する。料金や周期を候補の参考値として入力していないことも確認する。
4. 入力済みの別名を置き換える確認で、承認とキャンセルを試す。空欄・同名では直接反映され、選択後も名前を手修正できることを確認する。
5. 一覧から戻る操作と「その他・手入力」で入力が残り、後者では名前入力に進めることを確認する。種類を保険などへ変更すると入口が隠れ、戻しても名前が変わらないことを確認する。
6. 選択だけで契約・支払予定が増えないこと、契約追加のキャンセル、金額未入力の保存エラーと入力保持、保存・再起動後の名前を確認する。既存契約の編集には候補選択の入口が出ないことを確認する。
7. 候補一覧は端末内の定義で、外部からの名前・料金・ロゴの取得を行っていないことを確認する。機内モードでの確認時にも同じ候補が使えることを記録する。

## 追加機能と保存時終了の確認

1. 既存アプリを削除せず更新し、既存の取引・ジャンル・月間予算を確認する。データを消さずに移行できることを確認する。

5. カレンダーを開き、記録のある日のドット、日付選択、月移動、保存・日付編集・削除後の反映を確認する。
