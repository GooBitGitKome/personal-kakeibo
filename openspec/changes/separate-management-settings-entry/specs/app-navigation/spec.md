# Spec Delta

## Purpose

日々の記録と状況確認に必要な5つの主要画面を利用でき、口座・契約・所有物などの管理機能とアプリ設定の入口を見分けられるナビゲーションを提供する。

## ADDED Requirements

### Requirement: 独立した管理タブ
アプリは「入力」「履歴」「ホーム」「リマインダー」「管理」の5タブを提供しなければならない（SHALL）。管理画面のタイトルは「管理」とし、初回案内でも管理機能の入口を「管理」と案内する。

#### Scenario: 主要画面から管理へ移動する
- **WHEN** 利用者が入力、履歴、ホーム、リマインダーのいずれかから「管理」を選ぶ
- **THEN** 管理画面が開き、タブは5つのまま表示される

#### Scenario: 初回案内から通常画面へ進む
- **WHEN** 利用者が初回案内から契約または所有物の追加へ進む
- **THEN** 同じ追加画面が開き、キャンセルすると管理タブが選択された通常画面へ戻る

### Requirement: 管理一覧と設定入口の分離
管理一覧は口座・カード・振替、支払予定、契約・サブスクリプション・保険、所有物・修理費の4つの入口を提供しなければならない（SHALL）。設定は一覧に含めず、管理画面右上の歯車から開けなければならない（SHALL）。

#### Scenario: 管理項目を開いて戻る
- **WHEN** 利用者が管理一覧の項目を選ぶ
- **THEN** 対応する既存画面が開き、戻ると管理一覧へ戻る

#### Scenario: 設定を開いて戻る
- **WHEN** 利用者が管理画面右上の歯車を選ぶ
- **THEN** 既存の設定画面が開き、戻ると管理画面へ戻る

### Requirement: 設定ボタンの操作性
設定の歯車ボタンは幅・高さとも44pt以上の操作領域を持ち、アクセシビリティ名を「設定」としなければならない（SHALL）。

#### Scenario: 設定ボタンを識別する
- **WHEN** 利用者がVoiceOverで管理画面右上の歯車にフォーカスする
- **THEN** 「設定」と識別でき、ボタンを実行すると設定画面が開く
