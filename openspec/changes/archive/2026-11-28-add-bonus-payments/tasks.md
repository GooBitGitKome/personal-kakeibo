## 1. 金額の計算

- [x] 1.1 `InstallmentSchedule.split(principal:amounts:)` を公開し、`make` がこれを呼ぶ形にする。入力は各回の支払額（すべて 1 以上、1〜1,200 件、合計は購入額以上）。確認: `make` の既存の試験が変更なしで成功し、不揃いな金額の配列でも、合計の一致と 0 ≤ 利息 ≤ 支払額が成り立つことを、小さい値の全組み合わせで確認する試験が成功する。
- [x] 1.2 `PersonalKakeibo/Domain/BonusSchedule.swift` に、支払日の配列・ボーナス月・加算額から、各回の支払額・元本・利息を返す純関数を実装する。ボーナス月の回が 0 件、加算額が 1 円未満、毎月の部分が回数未満は `FinanceError.invalid`。確認: 仕様の例（6 月・12 月、20,000 円加算 → 25,833 円・5,837 円・5,833 円）、最終回がボーナス月、月末の支払日、小さい金額の試験と、回数・ボーナス月の組み合わせの性質試験（合計の一致、0 ≤ 利息 ≤ 支払額）が成功する。
