# Proposal

## Why

現在はサブスクリプションの追加でもサービス名を手入力するため、よく使うサービスを登録するたびに入力が必要になる。主要サービスを候補から選んで名前だけを入力できるようにし、実際の契約額や周期は利用者自身が指定できるようにする。

## What Changes

- 新規契約の種類が「サブスクリプション」のとき、「サービスから選ぶ」を表示する。初回案内から開いた追加画面も対象とする。
- 動画・音楽・クラウド・ソフトウェアなどのサービス名を、端末内の候補一覧から選べるようにする。
- 選択結果はサービス・契約名だけへ反映する。金額・支払周期・カテゴリ・日付・支払元などは選択前の入力を維持する。
- 名前が入力済みの場合は、別名への置き換えを確認する。選択後も名前を編集でき、「その他・手入力」も利用できる。
- 候補選択だけでは保存せず、既存の「保存」操作で契約を登録する。既存契約の編集は現在の手入力を使う。

## Capabilities

### New Capabilities

- `subscription-service-selection`: 新規サブスクリプション契約のサービス名選択と、入力中の契約情報の保護。

### Modified Capabilities

なし。

## Impact

契約追加画面、同梱するサービス候補と選択画面、UIテスト、README・確認手順に影響する。外部API、料金データ、ロゴ取得、保存モデルやバックアップ形式の変更は不要。

利用者との確定事項は「サービス名だけを入力する」こと。初期候補14件、カテゴリ別一覧、新規契約だけに表示する範囲は本提案の既定値とする。候補は人気順位ではなく、一覧にないサービスは手入力で登録できる。
