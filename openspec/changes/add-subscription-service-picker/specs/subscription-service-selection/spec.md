# Spec Delta

## Purpose

新規のサブスクリプション契約を追加する際に主要サービスの名前を候補から選べるようにし、金額や周期など利用者の実際の契約条件と入力中の情報を保ちながら登録を進められるようにする。

## ADDED Requirements

### Requirement: 新規サブスクリプションのサービス選択
アプリは、新規契約の種類がサブスクリプションの場合に「サービスから選ぶ」を表示しなければならない（SHALL）。管理画面と初回案内からの追加の両方で利用できなければならない（SHALL）。

#### Scenario: サービス候補を開く
- **WHEN** 利用者が新規サブスクリプションの追加画面で「サービスから選ぶ」を選ぶ
- **THEN** 主要サービス名をカテゴリ別に選べる一覧が開く

#### Scenario: 他の契約種類や既存契約を扱う
- **WHEN** 新規契約でサブスクリプション以外の種類を選ぶ、または既存契約を編集する
- **THEN** サービス選択の入口は表示せず、名前を手入力で編集できる

### Requirement: サービス名だけを反映する
候補の選択はサービス・契約名だけに反映しなければならない（SHALL）。金額・支払周期・カテゴリ・日付・支払元など他の入力値を変更してはならない（MUST NOT）。選択後の名前も自由に編集できなければならない（SHALL）。

#### Scenario: 入力中の契約に候補を適用する
- **WHEN** 金額・周期・カテゴリ・日付・支払元を入力した後にサービス候補を選択する
- **THEN** 選んだ名前だけが反映され、他の入力値は選択前と一致する

#### Scenario: 選択した名前を編集する
- **WHEN** 利用者が候補の選択後にサービス・契約名を編集する
- **THEN** 編集した名前で既存の保存操作を行える

### Requirement: 入力済みの名前を保護する
現在の名前が空欄でも選択候補と同名でもない場合、別名へ置き換える前に確認しなければならない（SHALL）。確認をキャンセルした場合は入力中の名前を変更してはならない（MUST NOT）。

#### Scenario: 名前の置き換えを承認する
- **WHEN** 名前を入力済みの利用者が別のサービスを選び、置き換えを承認する
- **THEN** 名前だけを選択候補へ置き換え、契約の入力画面へ戻る

#### Scenario: 名前の置き換えをキャンセルする
- **WHEN** 利用者が名前の置き換え確認をキャンセルする
- **THEN** 候補一覧に留まり、元の名前と他の入力値を保つ

### Requirement: 手入力と候補選択のキャンセル
候補一覧は「その他・手入力」を提供しなければならない（SHALL）。それを選ぶか一覧から戻る場合は契約の入力画面へ戻り、入力値を消してはならない（MUST NOT）。

#### Scenario: 一覧にないサービスを登録する
- **WHEN** 利用者が「その他・手入力」を選ぶ
- **THEN** 契約の入力画面へ戻り、任意のサービス名を入力して登録できる

#### Scenario: 候補を選ばずに戻る
- **WHEN** 利用者が候補一覧から戻る
- **THEN** 名前を含む契約の入力値は一覧を開く前のまま保持される

### Requirement: 端末内で使える候補一覧
候補一覧は通信できない状態でも利用できなければならない（SHALL）。料金や支払周期を候補の参考値として表示・入力してはならない（MUST NOT）。

#### Scenario: オフラインでサービスを選ぶ
- **WHEN** 通信できない状態で新規サブスクリプションを追加する
- **THEN** 同じ候補一覧から名前を選べ、金額や周期は利用者自身が入力できる

### Requirement: 既存の保存動作との互換性
候補選択だけで契約や支払予定を保存してはならない（MUST NOT）。保存後の名前は通常の契約名として扱い、候補一覧の更新で既存の契約名を書き換えてはならない（MUST NOT）。

#### Scenario: 選択した契約を保存またはキャンセルする
- **WHEN** 利用者が候補選択後に契約の保存またはキャンセルを選ぶ
- **THEN** 保存では既存の入力検証を通して契約を登録し、キャンセルでは契約や支払予定を追加しない

#### Scenario: 保存に失敗する
- **WHEN** サービス候補から名前を入力した契約の保存に失敗する
- **THEN** エラーを表示して入力を保持し、契約や支払予定を部分的に追加しない
