# Spec Delta

## Purpose

日々の記録や状況確認から設定へ迷わず移動でき、管理内の予定確認へ通知からも直接進めるように、主要タブと管理画面の役割を明確にしたナビゲーションを提供する。

## ADDED Requirements

### Requirement: 設定を含む5つの主要タブ
アプリは「入力」「履歴」「ホーム」「管理」「設定」の順に5タブを表示しなければならない（SHALL）。設定は独立したタブから開き、管理画面の設定の歯車は表示してはならない（MUST NOT）。

#### Scenario: 設定を直接開く
- **WHEN** 利用者が任意の主要タブから「設定」を選ぶ
- **THEN** 設定画面が開き、管理画面へ戻る操作を必要としない

### Requirement: 管理内のリマインダー
管理画面は既存の口座、支払予定、契約、所有物に加えてリマインダーの入口を提供しなければならない（SHALL）。リマインダーから戻ると管理画面へ戻らなければならない（SHALL）。

#### Scenario: 管理からリマインダーを開く
- **WHEN** 利用者が管理画面のリマインダーを選ぶ
- **THEN** 既存の予算残額・繰り返し収支の画面を開き、戻ると管理画面を表示する

### Requirement: 通知からリマインダーを直接表示
アプリは通知を開いたとき、管理タブ内のリマインダーへ直接移動しなければならない（SHALL）。同じ通知操作を繰り返しても、リマインダー画面を重複して積み上げてはならない（MUST NOT）。

#### Scenario: 別の画面から通知を開く
- **WHEN** 設定や別の管理画面を表示している状態で通知を開く
- **THEN** 管理タブが選択され、リマインダーが1画面だけ開く

### Requirement: 初回作成経路の維持
初回案内から契約・所有物の追加を選んだとき、管理タブを選択して対応する追加画面を開かなければならない（SHALL）。

#### Scenario: 初回作成をキャンセルする
- **WHEN** 初回案内で開いた契約または所有物の追加をキャンセルする
- **THEN** 管理タブが選択された通常画面へ戻る
